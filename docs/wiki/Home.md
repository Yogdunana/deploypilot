## What is DeployPilot?

DeployPilot solves the problem of AI IDEs (TRAE Solo, Coze, Cursor, Claude, SOLO) running in cloud sandboxes that cannot directly SSH to servers for deployment. It also supports enterprise servers behind bastion/jump hosts.

### Key Features

- **52+ MCP Tools** — Full deployment lifecycle management
- **Multi-Server** — Manage multiple servers from one dashboard
- **Docker** — Container lifecycle management
- **DNS** — Cloudflare, Alibaba Cloud, Tencent Cloud, WestDNS
- **SSL** — Automatic certificate management
- **CI/CD** — GitHub Actions and Gitea integration
- **OAuth** — GitHub and Gitee login
- **RBAC** — Role-based access control
- **Audit** — Comprehensive operation logging
